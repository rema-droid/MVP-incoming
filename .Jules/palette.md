## 2025-02-17 - Responsive Search Clearing & Refocus Pattern
**Learning:** In responsive layouts containing independent desktop (sidebar) and mobile (inline header) search inputs, clearing search inputs or running into a empty/error state requires intelligent, context-aware focus restoration. Simply calling `.focus()` on a static ref can cause scroll jank or silent failures if that ref points to an element hidden on the current viewport.
**Action:** Detect viewport width (`window.innerWidth >= 1024`) or element visibility before executing programmatic focus restoration. Use clear visual indicators (X buttons within the inputs, clean secondary action buttons in empty states) and explicit accessibility attributes (`aria-label`, `aria-controls` where applicable) to maintain intuitive keyboard and screen reader accessibility.
