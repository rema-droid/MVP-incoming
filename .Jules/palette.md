## 2025-05-14 - Search Input Pattern
**Learning:** Standardized search inputs should include a visually hidden label (sr-only) linked via id/htmlFor, a conditional 'Clear' button (X icon from lucide-react) with aria-label="Clear search", and appropriate padding (pr-10) to accommodate the button without text overlap. This ensures both accessibility and a smooth user experience.
**Action:** Apply this pattern to all search fields in the app to maintain consistency and accessibility.
