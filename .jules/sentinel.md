## 2026-08-10 - Proxy Bypass and SSRF via Path-Absolute URLs in JS URL Constructor
**Vulnerability:** Standard proxy endpoints that resolve upstream URLs by joining a relative path parameter with an upstream base URL (e.g. `new URL(path, base)`) are vulnerable to Server-Side Request Forgery (SSRF) and proxy destination bypass if the incoming path parameter starts with `//` (a protocol-relative URL) or a protocol scheme. The JS `URL` constructor treats these path-absolute strings as standalone hosts rather than sub-paths relative to the base host, resolving to the attacker's target origin instead.
**Learning:** Checking `upstream.origin !== base.origin` is a simple, generic, and extremely robust defense-in-depth measure that entirely mitigates URL resolution overrides and bypasses.
**Prevention:** Always validate that the fully resolved upstream URL's origin strictly matches the expected base URL's origin, and strip sensitive cookie/authorization headers before forwarding proxied requests to untrusted environments.
