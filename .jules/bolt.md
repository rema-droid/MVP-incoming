## 2025-05-15 - Redundant regex/array allocation and missing memoization in core utility
**Learning:** Functions like `summarizeRepoForBeginners` that perform heavy string processing and regex matching can become bottlenecks when called frequently (e.g., in lists or feeds). Hoisting static constants like the ~75-item `SWAPS` array and regex literals out of function bodies provides immediate allocation-free performance wins. Furthermore, implementing a bounded FIFO cache is essential for persistent environments to avoid memory growth while providing O(1) hot-path performance.
**Action:** Always hoist static data structures out of high-frequency functions. Use the `setWithEviction` pattern with separate key tracking arrays for multiple caches to ensure correct FIFO eviction behavior.
