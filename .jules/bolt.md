## 2025-05-15 - Single-Pass RegExp and FIFO Caching for Text Processing
**Learning:** Sequential `.replace()` operations in utility functions like `simplifyWords` run O(N) regex evaluations per invocation. Combined with rendering in item lists, this causes high CPU usage. Compiling a module-hoisted, length-sorted single-pass RegExp replacer mapped against an O(1) dictionary reduces processing time from O(N) to O(1) matching passes. Adding a small FIFO Map-based cache on the parent function `summarizeRepoForBeginners` prevents redundant calculations across component renders entirely.
**Action:** Always prefer hoisted single-pass token/regex matching over nested loops or chained/sequential replace chains when performing multi-word string replacements on user paths. Use a small capacity Map for memoization of pure utility functions in loop/list contexts.
