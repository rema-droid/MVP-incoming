## 2026-06-05 - Optimize RepoCard rendering and implement summary caching
**Learning:** Rendering large lists of `RepoCard` components was hampered by expensive SVG backdrop generation and regex-heavy summary logic being executed for every item, even when not visible or redundant. Wrapping components in `React.memo` and deferring expensive calculations to specific variants significantly reduces rendering lag. Map-based caching for pure utility functions like `summarizeRepoForBeginners` provides a massive speedup (~30x) for repeated repository metadata.
**Action:** Always check if expensive UI asset generation (like dynamic SVGs) or complex string processing can be deferred to specific component variants or cached at the utility level. Use `React.memo` for components rendered in large lists.
