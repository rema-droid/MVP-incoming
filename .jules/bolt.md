## 2025-02-17 - Hoisting Regex and Cache-Control for NLP Jargon Simplifier
**Learning:** In a highly interactive React/Next.js UI with frequent user keypress inputs, search mode toggles, and infinite scrolling, executing natural language parsing or dictionary glossary swaps inline (such as compiling 75 complex regex patterns dynamically on every render frame for every card) induces extremely severe layout blocking and CPU execution overhead. Hoisting compilation of regex matches out of rendering functions and implementing a strict, bounded FIFO cache reduces metadata preparation time by over 98%.
**Action:** Always inspect helper functions that perform string operations or text transformations inside loops or React rendering pathways. Ensure that mapping arrays, literal regex compilers, or heavy lookup dictionaries are declared at the module level rather than inside execution blocks. For deterministic conversions based on object attributes, protect hot paths with low-overhead O(1) key-based caches.
