## 2025-07-30 - React 19 Component Re-render Cascade with Search Input
**Learning:** In this codebase, the parent `Home` component manages the search query state directly, causing a full component re-render on every single keystroke. Because children like `RepoCard` and `FeedCard` are rendered in large numbers (>32 items) and perform expensive calculations (SVG generation and jargon simplified summaries), this rendering cascade heavily degrades typing responsiveness. Wrapping children in `React.memo` is only half the battle; callback handlers like `handleRepoView` and `handleRunRepo` must be wrapped in `useCallback` to prevent child memoization from being invalidated by changing function references.
**Action:** When working with search inputs or polling intervals in parent components, always wrap expensive child list items in `React.memo` and strictly stabilize any callback props using `useCallback` to avoid breaking the shallow-comparison optimization.
