## 2026-04-01 - Component Optimization and Computation Deferral for Large Lists
**Learning:** In highly interactive React apps featuring heavy parent component state updates (such as input searches, tab changes, and interval-based job polling), child components rendered in lists (`RepoCard`) must be wrapped in `React.memo` to eliminate wasteful visual re-renders. Furthermore, postponing heavy metadata/layout computations (like SVG backdrop generation and color palette determinations) to only run when the active layout variant requires them (`variant === "widget"`) yields highly measurable performance wins, reducing non-widget list rendering overhead.
**Action:** Always wrap standard list items/cards in `memo`, use `useMemo` for pure string transformation utilities, and defer heavy layout generation behind variant-specific conditional checks.
