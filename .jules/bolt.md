## 2026-08-01 - Active-Polling & High-Frequency Render Cascades with Expensive Children
**Learning:** In a dashboard utilizing active interval-polling (such as the 2-second background job status checker) combined with synchronous keystroke search states, the lack of memoization and callback stabilization causes entire lists of complex card components to completely re-render on every state change. When child cards perform synchronous regular expressions, string parsing, or heavy SVG dynamic backdrop generation (including URI encoding), this results in severe keyboard lag and CPU spikes.
**Action:** Always wrap list items in `React.memo` and stabilize parent event-handlers using `useCallback`. Furthermore, lazy-evaluate heavy calculations inside of child components based on active display variants, and ensure parent-level tab structures only run complex grouping calculations (e.g., categorizing files or datasets) when the matching tab is actively active and visible.
