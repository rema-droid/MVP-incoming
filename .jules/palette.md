## 2025-05-14 - Standardized Search and Active Navigation State
**Learning:** Standardizing search input behavior (adding clear buttons, accessible labels, and persistent IDs) and indicating the current page in navigation significantly improves both usability and accessibility. Using aria-current="page" is the standard way to communicate the active link to assistive technologies.
**Action:** Apply the standardized search input pattern (sr-only label, clear button, z-index for interactivity) and aria-current for active states in all navigation-heavy components.
