## 2025-03-08 - Accessible Toggles and Focus Path Optimization
**Learning:** Custom UI controls (such as App Store-style toggle switches) that rely on visually hiding native checkboxes (`sr-only`) can inadvertently break keyboard accessibility if visual focus is not correctly transferred to the styling element. Combining Tailwind's `peer` utility on the hidden input with `peer-focus-visible` on the adjacent wrapper element cleanly restores visual keyboard navigation without cluttering the accessibility tree.
**Action:** Always style customized check/toggle inputs with `.sr-only.peer` and configure corresponding outline/ring indicators on adjacent visual divs via `peer-focus-visible` classes. Ensure adjacent thematic/functional action buttons also possess explicit focus visible rings (`focus-visible:ring-2`) and clear outlines.
