## 2025-05-14 - Clearable Search Inputs
**Learning:** When implementing clearable search inputs with an absolutely positioned "X" button, it is critical to add sufficient right padding (e.g., `pr-9` or `pr-10`) to the input field itself. This prevents user-entered text from rendering underneath the clear button, maintaining both visual polish and legibility.
**Action:** Always pair absolute-positioned input decorators with corresponding padding on the input element.
