## 2025-08-04 - Accessible Custom Toggle Switches in React & Tailwind
**Learning:** In applications utilizing styled custom toggle switches (where standard checkboxes are hidden with `sr-only`), keyboard accessibility is frequently broken. Simply hiding the checkbox removes all standard visual focus indicator rings from the viewport. To resolve this, utilizing Tailwind's sibling state utility `peer` is essential: styling the adjacent visible container wrapper with `peer-focus-visible:*` ensures a high-contrast focus ring dynamically appears only during keyboard-triggered focus navigation (e.g. Tab), leaving mouse clicks visually clean.
**Action:** Always append `peer` to hidden `input` controls, and use `peer-focus-visible:ring-2` on adjacent custom-styled wrapper elements to ensure seamless visual indicators for assistive keyboard navigation.
